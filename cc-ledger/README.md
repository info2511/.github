# cc-ledger · 云端口径账本

本机账本（`~/projects/repo-governance`）靠扫本机文件系统建账，其自述的缺口是
「✗ 天生扫不到：另一台 Mac · 云端（须 API 拉取对账）」。

本目录补的是**云端那一半**：由云端 Claude Code 会话通过账号级 API 拉取、落盘、
进 git。两边共用一个 GitHub remote，因此这是本机与云端**都能到达**的唯一账本位置。

## 分工

| 层 | 载体 | 放什么 |
|---|---|---|
| 账本层 | 本 repo | 正文、原始数据、勘误。取代链＝git history |
| 呈现层 | Published Artifact | 给人看的图表视图，非 SSOT |
| 索引层 | 会话 tags | 战线代号，使 `list_sessions` 可按战线过滤 |

## 记账规范（沿用既有台账约定）

- **证据分级**：〔实测〕本会话跑出来的 ·〔文档〕出自一手文档 ·〔待确认〕未验证
- **缺口编号**：本账本用 `C-nn`（Cloud）前缀，**不占用**治理统筹台账的 `P-nn` 空间；
  并入时由台账持有人重新分配编号
- **取代链**：写在每份文件头部，明写取代谁
- **证伪留档**：被推翻的判断单列一节，不删——留着比结论有用
- **口径声明**：每份文件必须写清「谁、何时、在哪个容器、用什么工具」测的

## 已知不可达（本账本天生的边界）

- 任何会话的**对话正文**——云端无 transcript 读取工具，只有元数据
- **容器 B**（`3f77a70f/7a3104b8`，wed@）的会话——见 C-01
- 本机文件系统、另一台 Mac（.105）
