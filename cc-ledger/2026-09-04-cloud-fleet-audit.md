| 日期 | 云端登记 |

**对照实验。**去掉 `mine: true` 重查，返回的前 5 条与带该参数时完全一致〔实测〕。
故非调用方过滤所致，**是 API 本身账号作用域**。

**性质。**与该台账层 1 诊断的本机盲区**同型**：够不到的部分静默返回少的，不报错。
本机是 app 把作用域钉死在当前容器；云端是 API 钉死在当前账号。换了位置，错法不变。

**补法。**须在 wed@ 账号下开一个窗口跑同样的盘点，两份合并。本账本目前**只覆盖容器 A**。
